# clipboard

剪贴板历史。NSPasteboard 500ms 轮询（`changeCount` 对比），文本/图片/文件持久化到 SQLite；支持收藏、一键粘贴（写入 + 模拟 Cmd+V）。

monitor 的 pasteboard 访问全部委托至 `platform::pasteboard`（change_count / marker / 文本 / PNG / TIFF / file URL 解析）。Cmd+V 模拟通过 `platform::input::post_combo("cmd+v", None)`。

源 app 识别：`pasteboard_write_text`（copyAndHide / 复制路径等 Voidnix 内部写入）带 source marker（`com.litiantao.voidnix.source`），monitor 据此标记 `source_app = "Voidnix"`（仍入库）。外部复制无 marker，用 `NSWorkspace.frontmostApplication` 取真实来源（Voidnix 是 accessory app，frontmostApplication 不返回自身，故外部复制能正确标记真实 app）。

## 配置

`extensions/clipboard/config.ts`（defineConfig 自管）：

```typescript
defineConfig('extensions/clipboard/config', { maxDays: 30 })
```

`maxDays` 通过 `watch(immediate: true) → invoke(set_clipboard_max_days)` 推入 Rust 全局 `AtomicI32`（替代 Rust 直读 config.json，对齐 window-manager 样板）。

## 数据存储

`extensions/clipboard/clipboard.db`（SQLite WAL）。`Database::open` 返回 `Result`：目录/打开/建表失败时 setup 降级（不 manage、不启 monitor），命令 `try_state` 返回「剪贴板数据库不可用」，**禁止 expect 拖垮进程**。表 `clipboard_history`：

- `id`（毫秒时间戳）、`content`（文本原文 / `data:image/png;base64,...` / path-based `file://` URL；Finder 写入的 file reference URL `file:///.file/id=...` 经 `NSURL.filePathURL` 解析为实际路径后存为 `file://{path}`）、`content_type`（text/image/file）
- `source_app`、`created_at`（本地时间 `datetime('now','localtime')`；重复项 UPDATE 刷新）、`is_favorite`
- `file_size` / `image_width` / `image_height`（迁移列）

索引 `idx_clipboard_created_at`。图片 base64 内联存储，不外部落盘。

**WAL 增长控制**：每次 INSERT 后 `Database::maybe_checkpoint(&conn)` 累计计数，达 200 触发 `PRAGMA wal_checkpoint(TRUNCATE)`，防止 `clipboard.db-wal` 长期累积。

## 约束

- 轮询须在主线程访问 NSPasteboard（AppKit 要求），mpsc channel 回传
- 启动时只建立 changeCount 基准，不入库当前剪贴板已有内容（只记录启动后变化）
- 自身写入带 marker `com.litiantao.voidnix.clipboard` 防回环；`TransientType`/`ConcealedType`/`AutoGeneratedType` 跳过（密码管理器）
- 密码管理器源 app（1password/bitwarden 等）+ 内容像 secret（`password=` 等赋值前缀、PEM 私钥头）→ 不入库（兜底 ConcealedType 未设的密码管理器）
- 纯 emoji 跳过
- 类型优先级：FileURL 优先（访达复制文件常带图标 TIFF/PNG，位图优先会误判图片；图片扩展名 png/jpg/jpeg/gif/webp/bmp/heic 读文件转 base64 data URL 归类 image，>10MB 不转归类 file；其余扩展名归类 file）> PNG/TIFF（无 file URL 时，截图/浏览器复制图片；TIFF 经 NSBitmapImageRep 转 PNG）> String
- 多选文件：遍历 `NSPasteboard.pasteboardItems` 取所有 file URL（`read_file_urls`），每个文件入库一条（单次复制产生多条记录）；file reference URL `file:///.file/id=...` 经 `NSURL.filePathURL` 解析为实际路径。批量复制 >10 个直接丢弃整批（避免大量 base64 同驻内存 + 主线程逐文件解码阻塞）
- 粘贴：任意 `data:image/*;base64,` 经 `platform::pasteboard::set_image_bytes` 解码统一转 PNG 写入（NSImage 中转，支持 JPEG/GIF/WebP/BMP/HEIC 等所有系统格式；NSBitmapImageRep 不支持 HEIC 故经 NSImage → TIFF）
- 清理：config `maxDays` >0 按天删，<=0 按上限 5000 裁剪（仅非收藏）
- 默认拉取上限 500 条（全局搜索 dynamic 与模块列表）

## 删除

- 手动：`⌘⌫`（`View.vue` `onKeyStroke` → `triggerDelete` → `handleDelete`），多选优先否则取光标项，二次确认后调 `delete_clipboard_items`
- 清空 / 自动清理：均 `WHERE is_favorite = 0`，保留收藏
