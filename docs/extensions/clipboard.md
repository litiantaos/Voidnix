# clipboard

剪贴板历史。NSPasteboard 500ms 轮询（`changeCount` 对比），文本/图片/文件持久化到 SQLite；支持收藏、一键粘贴（写入 + 模拟 Cmd+V）。

## 数据存储

`extensions/clipboard/clipboard.db`（SQLite WAL）。表 `clipboard_history`：

- `id`（毫秒时间戳）、`content`（文本原文 / `data:image/png;base64,...` / `file://...` URL）、`content_type`（text/image/file）
- `source_app`、`created_at`（重复项 UPDATE 刷新）、`is_favorite`
- `file_size` / `image_width` / `image_height`（迁移列）

索引 `idx_clipboard_created_at`。图片 base64 内联存储，不外部落盘。

## 约束

- 轮询须在主线程访问 NSPasteboard（AppKit 要求），mpsc channel 回传
- 自身写入带 marker `com.litiantao.voidnix.clipboard` 防回环；`TransientType`/`ConcealedType`/`AutoGeneratedType` 跳过（密码管理器）
- 类型优先级：FileURL > String > PNG
- 清理：设置 `clipboard.maxDays` >0 按天删，<=0 按上限 5000 裁剪（仅非收藏）

## 删除

- 手动：`⌘⌫`（`View.vue` `onKeyStroke` → `triggerDelete` → `handleDelete`），多选优先否则取光标项，二次确认后调 `delete_clipboard_items`（不过滤 `is_favorite`，选中即删）
- 清空 / 自动清理：均 `WHERE is_favorite = 0`，保留收藏
