# Voidnix

macOS 效率启动器。模块化架构，极简设计，原生性能。

## 技术栈

Tauri + Rust | Vue 3 + Vite + Bun | UnoCSS | Pinia | SQLite

## 功能

- [x] 应用与文件搜索（Spotlight 召回 + Nucleo 精排，拼音/中英混搜）
- [x] 剪贴板历史（天数清理、收藏、智能过滤）
- [x] 选词翻译
- [x] AI Chat
- [x] 系统唤醒
- [x] 计算器（输入数学表达式触发）
- [x] 汇率转换 / UUID / 时间戳 / IP / Base64（斜杠命令触发）
- [x] 右键菜单
- [x] 截屏 + 标注 + 滚动截屏 + OCR
- [x] 终端自动建议（终端输入显示自动建议）
- [x] 窗口管理
- [ ] 视频处理

## 快捷键

- `Option+Space`：唤起/隐藏主窗口
- `Tab`：切换搜索栏操作项
- `↑↓`：切换列表项
- `Enter`：执行选中项
- `Escape`：关闭窗口 / 返回界面
