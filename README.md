# Voidnix

macOS 效率启动器。模块化架构，极简设计，原生性能。

## 技术栈

Tauri + Rust | Vue 3 + Vite + Bun | UnoCSS | Pinia | SQLite

## 使用说明

### 基本

- 启动后常驻后台，无 Dock 图标
- 默认无菜单栏图标；代理已连接、保持系统唤醒已开启时显示
- `Option+Space` 唤起 / 隐藏主窗口，失焦自动隐藏
- `↑↓` 选择列表项，`Enter` 执行，`Escape` 退出当前层（子视图 → 模块 → 隐藏窗口）
- `Cmd+Enter` 显示结果菜单，如应用、文件/夹、剪贴板记录等
- 有右侧操作区时，`Tab` 在搜索栏与操作区控件间切换

### 全局搜索

- 默认列表显示按使用频率排序的应用
- 输入关键字搜索应用、文件/夹、扩展等，结果按 应用 → 扩展 → 文件 → 剪贴板 → 快捷操作 分组
- 输入 `/` 显示扩展列表
- 输入 `//关键词` Google、输入 `//b 关键词` Bing、输入 `//example.com` 打开链接

### 计算器

全局输入数学表达式即时计算（如 `1+2*3`），回车复制结果，模块内查看历史。

### 汇率

全局输入金额与币种即时换算（如 `100 USD`、`1万美元`），模块内查看全部币种与参考汇率。

### IP

进入模块后：空查本机公网，输入 IP 查归属。

### 时间戳

进入模块后：空显示当前时间，输入 Unix / 日期互转。

### UUID

进入模块后生成 UUID v4 / NanoID。

### Base64

进入模块后文本编解码。

### 剪贴板

后台自动记录文本、图片、文件；`Option+C` 打开历史，支持搜索、收藏、多选，回车粘贴，可配置保留天数。

### 翻译

`Option+T` 抓取当前选中文本进行翻译，或模块内直接输入，中英方向自动反转，可配置有道或 AI 引擎（多引擎并排）。

### AI Agent

`Option+A` 支持对话与工具调用（联网搜索、执行命令），可配置提供商与模型，命令默认直接执行。

### 截屏

`Option+S` 区域截屏后支持标注、OCR 与二维码识别、钉图、滚动长截图，默认保存到下载目录，路径可配置。需屏幕录制权限。

### 访达工具

`Option+F` 在访达中拷贝路径、终端打开、新建文件、切换隐藏文件。需辅助功能权限。

### 窗口管理

启用后，鼠标移至屏幕顶部中心唤起分屏面板，支持自定义尺寸。

### 代理

下载 mihomo 内核 → 添加订阅 → 开启（默认 TUN 模式，首次需管理员密码，之后常驻免提权）。支持节点切换、测速、规则模式，搜索栏右侧查看连接 / 规则 / 日志，连接后菜单栏可快速断开。

### 视频处理

压缩 / 转格式 / 抽音频，无系统 FFmpeg 时按需下载静态内核。

### 终端自动建议

开启后，zsh 输入时显示历史 frecency 建议，`→` 接受、`Tab` 切换备选、`Ctrl+X` 开关、`Ctrl+C` 清空。

### 保持系统唤醒

通过外接虚拟显示器实现 MacBook 合盖熄屏不休眠，仅在接入电源时可用。

### 系统状态

查看 CPU / 内存 / 磁盘 / 网络等概览。

### 清洁模式

开启后，全屏黑屏并锁定键鼠，**长按鼠标左键 2 秒**退出。

### 设置

启动快捷键、检查更新、退出，隐私权限入口（屏幕录制、辅助功能、完全磁盘访问），一键跳转系统设置。
